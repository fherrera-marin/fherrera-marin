# Fernando Herrera Marín

**Desarrollo de Software e Inteligencia Artificial | Ingeniero Mecánico | Investigador Predoctoral**

Soy Ingeniero Mecánico, con un Máster en Ingeniería de Sistemas y Automatización. Actualmente desarrollo mi investigación doctoral en la aplicación de técnicas de Inteligencia Artificial a la Dinámica de Fluidos Computacional (CFD).

He trabajado en el desarrollo, entrenamiento y evaluación de modelos de Deep Learning orientados a la predicción de campos aerodinámicos, utilizando Python, TensorFlow y Keras.

Paralelamente, me estoy especializando en desarrollo de software, trabajando con Python y Django para el backend, y JavaScript y React para el frontend, mediante la integración de APIs REST.

## Proyectos destacados

### Hybrid U-Net — Predicción de campos aerodinámicos

Desarrollo de una arquitectura neuronal híbrida basada en redes convolucionales y U-Net para la predicción de campos de velocidad y presión a partir de geometrías aerodinámicas representadas mediante funciones de distancia con signo (SDF).

[Repositorio Hybrid-UNET]([https://github.com/nandoherrera97-code/Hybrid-UNET](https://github.com/fherrera-marin/Hybrid-U-Net))

### CFD Surrogate Models — Wind Turbine Blades

Desarrollo de herramientas en Python para la generación de geometrías NACA y generación de dataset de resultados de simulación CFD mediante OpenFOAM.

[Repositorio CFD Surrogate Models](https://github.com/fherrera-marin/Automated-CFD-Results-Generator)
